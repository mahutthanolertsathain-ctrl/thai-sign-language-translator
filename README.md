# เว็บไซต์แปลภาษามือไทย

ต้นแบบเว็บไซต์แปลภาษามือไทยแบบสองทิศทาง มีระบบค้นหาคลิปภาษามือจากข้อความหรือเสียงพูด และระบบตรวจจับท่าทางผ่านกล้องในเบราว์เซอร์

เว็บไซต์เวอร์ชันปัจจุบัน: [https://code-amber-three.vercel.app](https://code-amber-three.vercel.app)

## ระบบที่มีในเว็บ

- **ค้นหาวิดีโอภาษามือ** พิมพ์คำหรือใช้ไมโครโฟนเพื่อค้นหาคลิปจากคลังวิดีโอ
- **จับท่าทางภาษามือ** ใช้กล้องและ MediaPipe ในเบราว์เซอร์เพื่อตรวจจับท่าที่รองรับ
- กล้องตรวจจับคำว่า **ฉัน, พ่อ, แม่, โกรธ, รัก, ป่วย/ไม่สบาย และช่วยฉันด้วย**

## การใช้งาน

เปิดเว็บไซต์ผ่าน HTTPS ด้วย Safari, Chrome หรือเบราว์เซอร์ที่รองรับ อนุญาตไมโครโฟนเมื่อใช้ค้นหาด้วยเสียง และอนุญาตกล้องเมื่อเริ่มระบบจับท่าทาง แนะนำให้จัดกล้องให้เห็นใบหน้า มือ และลำตัวช่วงอกชัดเจน และใช้มือขวาทำทีละท่า (ท่า “รัก” ใช้สองมือ)

โปรเจกต์นี้เป็นต้นแบบเพื่อสาธิตแนวคิด ความแม่นยำของการตรวจจับอาจแตกต่างตามอุปกรณ์ แสง และตำแหน่งกล้อง

## โครงสร้างไฟล์เว็บ

- `index.html` — หน้าเว็บหลัก
- `web-static/app.js` — การค้นหาคลิป เสียงพูด และส่วนติดต่อผู้ใช้
- `web-static/camera.js` — ตรวจจับท่าทางจากกล้อง
- `web-static/styles.css` — รูปแบบหน้าเว็บ
- `web-static/videos/` — คลิปวิดีโอที่เว็บใช้งาน
- `web-static/vocabulary.json` — คำค้นที่เชื่อมกับคลิป
- `vercel.json` — การตั้งค่าเผยแพร่เว็บไซต์แบบ static บน Vercel
