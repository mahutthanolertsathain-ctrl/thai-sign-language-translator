# เว็บไซต์แปลภาษามือไทย

ต้นแบบเว็บไซต์แปลภาษามือไทยแบบสองทิศทาง มีระบบค้นหาคลิปภาษามือจากข้อความหรือเสียงพูด และระบบตรวจจับท่าทางผ่านกล้องในเบราว์เซอร์

เว็บไซต์เวอร์ชันปัจจุบัน: [https://muepood.vercel.app](https://muepood.vercel.app)

## จุดประสงค์ของโครงการ

โครงการนี้จัดทำขึ้นเพื่อทดลองสร้างเครื่องมือที่ช่วยให้ผู้ใช้ภาษามือและผู้ใช้ภาษาไทยสื่อสารกันได้สะดวกขึ้น โดยมีทั้งการค้นหาคลิปภาษามือจากข้อความหรือเสียงพูด และการใช้กล้องตรวจจับท่าภาษามือเพื่อแสดงผลเป็นข้อความและเสียง เว็บไซต์นี้ยังเป็นต้นแบบเพื่อการเรียนรู้และพัฒนาต่อ โดยจำนวนคำและท่าที่ระบบรองรับยังมีจำกัด

## ระบบที่มีในเว็บ

- **ค้นหาวิดีโอภาษามือ** พิมพ์คำหรือใช้ไมโครโฟนเพื่อค้นหาคลิปจากคลังวิดีโอ
- **ฝึกทีละคำ** เลือกคำ ดูคลิป เปิดกล้องฝึก และแสดงผลเมื่อตรวจพบท่าที่เลือก พร้อมฝึกซ้ำหรือไปคำถัดไป
- **จับท่าทางภาษามือ** ใช้กล้องและ MediaPipe ในเบราว์เซอร์เพื่อตรวจจับท่าที่รองรับ
- กล้องตรวจจับคำว่า **ฉัน, เขา, หิว, อิ่ม, สวัสดี, สบายดี, พ่อ, แม่, ลุง, โกรธ, ร้องไห้, ยิ้ม, กลัว, ไม่ชอบ, รัก, ป่วย/ไม่สบาย และช่วยฉันด้วย**

## การใช้งาน

เปิดเว็บไซต์ผ่าน HTTPS ด้วย Safari, Chrome หรือเบราว์เซอร์ที่รองรับ อนุญาตไมโครโฟนเมื่อใช้ค้นหาด้วยเสียง และอนุญาตกล้องเมื่อเริ่มระบบจับท่าทาง แนะนำให้จัดกล้องให้เห็นใบหน้า มือ และลำตัวช่วงอกชัดเจน และใช้มือขวาทำทีละท่า (ท่า “รัก” “สวัสดี” “สบายดี” “ยิ้ม” และ “กลัว” ใช้สองมือ)

ระบบเตรียมเสียงอัตโนมัติเมื่อกด “พร้อมแล้ว เปิดกล้อง” ในโหมดแปลเป็นประโยค จึงไม่ต้องกดทดสอบเสียงแยกก่อนทำท่า

โปรเจกต์นี้เป็นต้นแบบเพื่อสาธิตแนวคิด ความแม่นยำของการตรวจจับอาจแตกต่างตามอุปกรณ์ แสง และตำแหน่งกล้อง

## โครงสร้างไฟล์เว็บ

- `index.html` — หน้าเว็บหลัก
- `web-static/app.js` — การค้นหาคลิป เสียงพูด และส่วนติดต่อผู้ใช้
- `web-static/camera.js` — ตรวจจับท่าทางจากกล้อง
- `web-static/styles.css` และ `web-static/redesign.css` — รูปแบบหน้าเว็บและการแสดงผลตามขนาดหน้าจอ
- `web-static/videos/` — คลิปวิดีโอที่เว็บใช้งาน
- `web-static/vocabulary.json` — คำค้นที่เชื่อมกับคลิป
- `vercel.json` — การตั้งค่าเผยแพร่เว็บไซต์แบบ static บน Vercel

รายละเอียดการเผยแพร่อยู่ใน [VERCEL_DEPLOY.md](VERCEL_DEPLOY.md)
